Tutorial

Tutorial Menggunakan Quality Method

1

Pilih Video

Drag & drop atau klik area upload untuk memilih file video (MP4, MOV, MKV, dll).

2

Pilih Versi TikTok & Kompresi

Pilih v1 atau v3 untuk hasil video terbaik. Mode ON = file lebih kecil dengan kualitas tetap tajam, mode OFF = tanpa kompresi.

3

Proses Video

Klik "Proses Video", periksa detail file di modal analisis, lalu klik "Proceed". Tunggu hingga encoding selesai.

4

Download Otomatis

File hasil akan langsung terdownload. Ukuran file jauh lebih kecil dengan kualitas HD tetap tajam.

Tutorial Upload di Media Sosial (TikTok, dll)

1

Gunakan v3 + Compress ON

Pilih v3 (MP4 H.264) dengan Compress ON untuk hasil paling tajam dan berukuran kecil, sangat direkomendasikan untuk TikTok.

2

Periksa Hasil di Modal

Pastikan FPS tampil ✅ (≤120 dan bulat) serta resolusi layak sebelum menekan Proses agar hasil optimal.

3

Upload via Aplikasi TikTok

Buka aplikasi TikTok, pilih Upload, lalu ambil file MP4 hasil kompresi dari galeri/download. Jangan kirim lewat WhatsApp agar tidak dikompres ulang.

4

Ukuran Ideal & Platform Lain

Unggah dalam ≤1080p dan 60fps. File MP4 yang sama juga bisa dipakai untuk Instagram Reels, YouTube Shorts, dan Facebook.
